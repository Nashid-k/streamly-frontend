Servers switcher (new UI)
- A Server icon in the transport row (movies and TV) opens a Servers sheet — also reachable from gear → the new "Servers" row.
- Three rows with honest capability one-liners:
  - VidCore — 4K · multiple qualities
  - VidSrc — Original audio · up to 1080p
  - NHD — Multi audio (dubs) · one quality
- VidCore is the default exactly as you ordered — first in the auto rotation and preselected in the menu.

Switch mechanics (no lying)
- Picking a server re-resolves through only that server (its own retry + token-refresh machinery intact) — no silent fallback to another provider. If it fails, the error says "{Server} had no playable stream — try another server" instead of quietly swapping providers.
- The NHD dub pin is cleared across servers so a dead old dub token can't leak into the new server's stream; the menu highlight survives a failed switch correctly (shows what you asked for, not what you abandoned).

Better audio naming
- The single-track fallback now reads "Original — {Film language}" (e.g. "Original — Telugu") instead of a bare "Original".
- All NHD sibling tracks now appear as rows. This fixed a real flaw: NHD's own player highlights tracks[0] while playing the main URL, so sibling[0] is not provably the original — my earlier layout hid a real language behind the "Original" row.
